# Experiment 000 — Mac test handoff

The Mac test bundle is generated by `scripts/package-mac-test.py` from the
verified marker ELF. Run `source scripts/env.sh` first so mtools/dosfstools are
available. Output: `artifacts/Delxr-Experiment-000-Mac-Test.zip` (60.8 MiB).

First handoff archive SHA-256:
`a58e61ead8fa3f38daf31933e0a21f6aa22d8bdc348e09651e019e1573c0c7cf`.
Newly generated cards/archive timestamps can change the ZIP checksum; payload
checksums are recorded inside each bundle in SHA256SUMS.

The bundle includes the verified marker ELF, a freshly formatted 256 MiB FAT32
card, a Bash launcher for the existing DelugEmu.app, a five-minute checklist,
licence notices, the complete baseline firmware source archive, marker patch,
Argon dependency and build instructions. No emulator binary or factory samples
are redistributed. See `packaging/macos/START-HERE.md` for the user instructions.

Validation performed:

- ZIP CRCs and every SHA256SUMS entry checked after extraction.
- Launcher Bash syntax and argument forwarding checked with a stub application,
  including an application path containing spaces.
- Extracted firmware and a copy of the packaged fresh card passed the Linux
  emulator smoke check: tempo OLED response, pad LED feedback, play/stop feedback
  and non-silent stereo audio. Testing changed only the extracted card, not the
  pristine image inside the downloadable ZIP.

macOS execution, CoreAudio speaker/headphone output and subjective latency remain
pending the user's test. The launcher was checked against the pinned upstream
macOS app launcher source; this is not a claim of native Mac execution.
Experiment 000 remains Partial until that check is complete.
